# 账房 ERP · 进销存与财务管理

一套**纯前端、单机可运行**的 ERP 演示系统：仪表盘、客户、产品、销售、供应商、采购、入库、出库、库存、财务对账、账号管控、操作日志、系统设置共 13 个模块，数据全部保存在浏览器本地，无需服务器。

## 功能清单

| 模块 | 能力 |
|---|---|
| 仪表盘 | KPI 总览（本月销售/采购、库存、应收应付、低库存）、近 12 周购销趋势、订单状态构成、分类库存金额、近 7 日资金收付、待办事项与业务动态 |
| 客户管理 | 客户档案增删改查、应收余额、订单/收款记录、对账单导出（CSV） |
| 产品管理 | 产品档案（售价/成本/安全库存）、分类管理、库存水位、库存流水、盘点调整 |
| 销售订单 | 建单 → 审核 → 销售出库 → 完成 → 收款，全流程状态机；按状态筛选、进度展示 |
| 供应商 | 供应商档案、应付余额、付款记录、对账单导出 |
| 采购单 | 建单 → 审核 → 采购入库 → 完成 → 付款，全流程状态机 |
| 入库单 | 采购入库（联动采购单余量）/ 其他入库，实时加库存并留流水 |
| 出库单 | 销售出库（联动销售单余量）/ 其他出库，库存不足自动拦截 |
| 库存管理 | 库存总览（含低库存水位）、连续结存流水、盘点调整（盘盈/盘亏留痕） |
| 财务对账 | 应收账款/应付账款、收付款登记（银行/现金/支付宝/微信/承兑）、资金流水、往来对账单（导出/打印） |
| 账号管控 | 账号增删改、启停、内置 6 角色 × 13 模块的「查看/操作」权限矩阵，可自定义 |
| 操作日志 | 登录日志（登录/切换账号）与操作日志（单据、档案、财务、账号的关键动作留痕），本机存储，管理员可清空 |
| 系统设置 | 公司信息、业务参数（低库存阈值/税率）、数据备份/恢复/重置 |

## 目录结构

```

├── css/
│   └── app.css              # 样式源文件（已内联进入口 html）
├── js/
│   ├── core.js              # 数据层：初始化数据、业务规则、库存/财务计算、操作日志
│   ├── ui.js                # UI 组件库：图标、弹层、表单、表格、印章、图表

│   ├── views2.js            # 销售订单 / 采购单 / 入库单 / 出库单
│   ├── views3.js            # 库存 / 财务对账 / 账号管控 / 操作日志 / 系统设置
│   ├── regions.js           # 省市县三级地址总源（34 省 366 市 3236 区县）
│   ├── regions/             # 地址数据拆分目录：34 个省份文件，文件名即省份名称
│   │   ├── 广西壮族自治区.js
│   │   ├── 广东省.js
│   │   └── ...（共 34 个）
```

> 入口 html 已把 css 与业务 js 内联合成（仅 ECharts 图表库走 CDN）。**全国地址数据按用户要求拆分为 `js/regions/` 下 34 个独立省份文件**（文件名直接用省份名称命名），入口 html 以 `<script src="js/regions/省份名.js">` 外链加载——因此 html 文件需与 `js/regions/` 目录放在一起使用（同目录复制），本地 `file://` 打开可正常加载。修改源码后可用 `rebuild_single.py` 重新合成。

## 运行 / 部署说明

1. **打开**：直接双击 `账房ERP管理系统.html`，用 Chrome / Edge 等现代浏览器打开即可，无需安装任何依赖。
2. **联网要求**：页面字体与图表库（ECharts）通过 CDN 加载，首次打开需要联网；加载失败会自动回退到系统字体，核心功能不受影响。
3. **数据存储**：所有业务数据保存在当前浏览器（localStorage）中，换电脑 / 换浏览器 / 清除浏览器数据前，请在「系统设置 → 数据管理」先**导出备份**。
4. **默认账号**：内置 6 个账号，密码均为 `123456`：
   - `admin` 账房掌柜（管理员，全权限）
   - `linxiao` 林晓（销售专员）、`chenbin` 陈斌（采购专员）、`zhouqiang` 周强（仓库管理员）、`suqing` 苏晴（财务专员）、`visitor` 访客小王（只读）
   - 登录页输入**账号与密码**登录（密码必须与账号匹配，不可留空）；顶栏头像菜单可「锁屏 / 切换账号」退出到登录页重新登录，导航与操作按钮按角色权限实时变化。
5. **业务口径**：应收/应付按「审核后且未取消」的单据计算，已收/已付取自收付款登记；库存以出入库单与盘点调整流水为准，期初 + 变动 = 现存量。
